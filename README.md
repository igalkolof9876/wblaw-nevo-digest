# wblaw-nevo-digest — Cowork (cloud routine) version

גרסת ענן של רוטינת "סקירת פסיקה יומית מנבו". מקור: `.claude-sync/skills/nevo-daily-digest`
על המחשב המקומי (עדיין קיים שם, ורץ במקביל דרך משימות מתוזמנות של האפליקציה - ראה
"מעבר הדרגתי" למטה).

## מה השתנה לעומת הגרסה המקומית

- **אין Outlook COM ואין Edge headless** - שניהם תלויי Windows מקומי. השליחה כבר הייתה
  Gmail MCP בלבד (החלטת יגאל מ-17.9.2026), אז זה לא שינוי בפועל. ה-PDF עכשיו נוצר עם
  `scripts/pdf_render.py` (WeasyPrint, פייתון טהור) במקום `msedge.exe --headless`.
  **לא נבדק עדיין בריצה אמיתית בענן** - ראה "פערים ידועים" למטה.
- **State עובר ב-git, לא בדיסק מקומי.** כל ריצה מקבלת checkout טרי מה-repo. בסוף כל
  ריצה מוצלחת (בעיקר שלב `send`), ה-routine עצמו מריץ `git add state/ && git commit && git push`
  כדי שהריצה הבאה תראה את ה-state המעודכן. אם ה-commit/push נכשל - יש לדווח על כך
  בפלט הריצה ולא להמשיך בשקט, כי בלעדיו הריצה הבאה תחזור על אותם פסקי דין.
- **בלי `--has-pdf` בכל מקרה** (ירושה מהגרסה המקומית) - הערוץ התקני נשאר קישור ל-Artifact.

## מבנה

```
scripts/    כל סקריפטי הפייתון (זהים לגרסה המקומית, חוץ מ-pdf_render.py החדש)
state/      seen.json (דדופליקציה) + pending.json בזמן ריצה - נשמר ב-git בין ריצות
README.md   הקובץ הזה
```

## פערים ידועים (לבדוק בריצה אמיתית ראשונה)

1. **PDF ב-WeasyPrint** - לא נבדק מול HTML האמיתי של הדיגסט. אם הפגינציה או ה-RTL
   נראים שבורים, זה המקום הראשון לבדוק. אין נפילה חזרה ל-Edge headless בענן - אין שם Windows.
2. **חיבורי MCP (Gmail, iManage)** - צריך לוודא בפועל שהם מחוברים ברמת חשבון claude.ai
   ומצורפים ל-routine, לא רק ברמת האפליקציה המקומית.
3. **גישה לאינטרנט מהענן ל-nevo.co.il** - `nevo_collect.py`/`nevo_fetch_text.py` משתמשים
   ב-`urllib` רגיל (Chrome UA כדי לעקוף חסימת 403). לא אומת שסביבת הענן (CCR) מאפשרת
   יציאה לאתר הזה.
4. **תזמון ה-cron הוא UTC קבוע** - לא זז אוטומטית עם שינוי שעון קיץ/חורף בישראל
   (בניגוד לתזמון המקומי שכבר בזמן ישראל). יש לעדכן ידנית פעמיים בשנה, או לבדוק מחדש
   סביב מעברי השעון.

## מעבר הדרגתי

הרוטינה המקומית (`nevo-digest-collect-1500` / `nevo-digest-send-1700` במשימות המתוזמנות
של האפליקציה) **לא בוטלה** בשלב זה. מומלץ להריץ את שתיהן במקביל כמה ימים, להשוות תוצרים,
ורק אז לכבות את המקומית.
