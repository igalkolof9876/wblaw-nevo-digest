**אחרי מסירה מוצלחת בלבד:**
1. הוסף את כל ה-vid-ים (גם מ-pending.json, גם מהניתוח הנוסף) ל-`state/seen.json` בפורמט `{"<vid>": {"date": "<ISO>", "case": "<שם>"}}`.
2. מחק את `state/pending.json`.
3. ```
   git add state/seen.json
   git rm -f state/pending.json 2>/dev/null || true
   git commit -m "send <תאריך ISO> - <מספר> פסקי דין"
   git push
   ```
   אם ה-push נכשל - נסה `git pull --rebase` פעם אחת ואז push שוב. אם עדיין נכשל, דווח על השגיאה המדויקת בתשובתך הסופית - קריטי, כי בלעדי ה-commit הריצה הבאה תדווח שוב על אותם פסקי דין.
