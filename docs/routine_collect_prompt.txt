אם לא נמצאו פסקי דין רלוונטיים, כתוב pending.json עם רשימת items ריקה. אם נבו מחזירה שגיאה, רשום זאת ב-pending.json תחת המפתח "errors" - אל תשתוק.

**בסיום, בין אם נמצא משהו ובין אם לא:**
```
git add state/pending.json
git commit -m "collect <תאריך ISO>"
git push
```
אם ה-push נכשל - נסה `git pull --rebase` פעם אחת ואז push שוב. אם עדיין נכשל, דווח על השגיאה המדויקת בתשובתך הסופית במקום להמשיך בשקט - זה קריטי, כי בלעדי ה-commit ריצת ה-send לא תראה את התוצרים של הריצה הזו.
